Формат Mystery Logic

Короткое дело. Честная логика.

«Кто врёт?» — серия детективных задач, где ответ определяется не совпадением с мнением автора, а проверяемым противоречием. Это может быть невозможное время, неверный маршрут, знание закрытой информации или физическое условие, которое нельзя выполнить одновременно с заявленной версией.

Начните с 15 бесплатных расследований. Для похожих форматов есть подборки: детективные игры онлайн, детективные загадки с ответами и логические детективные задачи.
