# Кто врёт? — веб-версия

Первый вертикальный срез браузерной версии детективной игры «Кто врёт?». Репозиторий содержит:

- WordPress-плагин `ktovret-game`;
- отдельный публичный тип записей для расследований с SEO-адресами `/delo/{slug}/`;
- мобильный игровой интерфейс без перезагрузки страницы;
- первое перенесённое дело «Запись до вскрытия контейнера»;
- подсказки, блокнот, выбор версии, разбор и локальное сохранение прогресса;
- автономную демонстрационную страницу `index.html`;
- GitHub Pages workflow для публикации демо.

## Контрольная точка

Это этап **web MVP 0.1.0**. Регистрация, WooCommerce, эквайринг и платный доступ пока намеренно не подключены.

`https://valera2872.github.io/ktovret-web/`

## Установка в WordPress

1. Скопировать каталог `ktovret-game` в `wp-content/plugins/`.
2. Активировать плагин **Кто врёт? — игровой движок**.
3. При активации создаётся демонстрационное расследование.
4. Открыть в админке раздел **Расследования**.
5. Страница дела получает адрес вида `/delo/zapis-do-vskrytiya-konteynera/`.

Для вставки игры на произвольную страницу:

```text
[ktovret_game slug="zapis-do-vskrytiya-konteynera"]
```

## Архитектура следующего этапа

- WordPress: SEO, страницы, админка, пользователи и платежи.
- `ktovret-game`: игровой цикл и данные расследований.
- WooCommerce: один виртуальный товар «Полный первый том».
- Серверная выдача платных дел только пользователям с подтверждённым доступом.
- PWA, аккаунт и синхронизация прогресса — после проверки бесплатного игрового MVP.
