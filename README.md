# Mystery Logic / Кто врёт? — веб-версия

Веб-проект первой игровой линейки экосистемы **Mystery Logic**.

- **Mystery Logic** — зонтичный бренд и будущий портал детективных форматов;
- **Кто врёт?** — короткие интерактивные расследования;
- `ktovret-game` — игровой движок и WordPress-плагин;
- каждое дело получает отдельный индексируемый адрес `/delo/{slug}/`.

## Установка игрового движка в WordPress

1. Скопировать каталог `ktovret-game` в `wp-content/plugins/`.
2. Активировать плагин **Кто врёт? — игровой движок**.
3. При активации создаётся демонстрационное расследование.
4. Открыть в админке раздел **Расследования**.
5. Страница дела получает адрес вида `/delo/zapis-do-vskrytiya-konteynera/`.

Для вставки игры на произвольную страницу:

```text
[ktovret_game slug="zapis-do-vskrytiya-konteynera"]
```
