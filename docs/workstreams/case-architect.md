## Quality target

Premium is not "more text".

Each case should aim for:
- fast hook;
- real investigative action;
- multiple viable hypotheses;
- causal red herrings;
- varied evidence;
- multi-step deduction;
- credible motives and lies;
- fair play;
- reconstruction;
- post-case explanation;
- memorable format-specific experience.

## Portfolio target

Existing monetization strategy uses approximately 6–8 strong Premium investigations as the working threshold before aggressive Club promotion.

The Case Architect should therefore optimize the portfolio, not produce random isolated cases.

## Safety / privacy

- case ID;

- exact next step.
