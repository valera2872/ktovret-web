# Mystery Corpus — Independent Reviewer Provider v1

Purpose: execute extraction review in a separate stateless context/provider without giving that provider permission to mutate the corpus.

## Boundary

Input to reviewer provider:
- extraction review contract generated by `build-extraction-review-prompt.mjs`;
- extraction result;
- source reference and rights evidence;
- required hard checks.

The provider does NOT receive:
- write access to private corpus;
- promotion credentials;
- permission to alter extraction output;
- permission to rewrite Case DNA during review.

## Identity separation

`reviewer_id` must:
- differ from `extractor_id`;
- match the ID requested by the caller;
- represent a context/provider that did not perform the extraction.

Changing a label is not sufficient separation if the same model context already performed the extraction.

## Execution

```
run-extraction-review-provider.mjs
        |
        v
external/stateless reviewer
        |
validate-extraction-review.mjs
        |
        v
review JSON
        |
run-review-promotion-check.mjs
        |
validate-ingestion-promotion.mjs
        |
        v
eligible_for_private_corpus OR blocked
```

The promotion-check orchestrator NEVER moves or copies files. It only establishes eligibility.

Environment:
- `CORPUS_REVIEWER_ENDPOINT`
- optional `CORPUS_REVIEWER_TOKEN`

The adapter behind the endpoint should have browsing/source-fetch capability for independent source verification. If it cannot open the cited source, it must not mark `critical_claims_supported=true`.
