## 001 · Протокол шести цифр

Код состоит из шести разных цифр. Для каждой строки точно указано, сколько цифр стоят на своих местах и сколько входят в код, но стоят в других позициях. Остальные цифры строки в код не входят.

- `970234` — 0 на месте · 3 не на месте
- `950314` — 0 на месте · 4 не на месте
- `053246` — 0 на месте · 3 не на месте
- `410259` — 0 на месте · 4 не на месте
- `130697` — 1 на месте · 2 не на месте
- `061759` — 1 на месте · 3 не на месте
- `145063` — 0 на месте · 4 не на месте
- `205387` — 1 на месте · 3 не на месте

**Вопрос:** какой код?

## 002 · Семь модулей

Семь модулей `A–G` стоят в один ряд. Каждый занимает ровно одну позицию.

1. A стоит раньше C.
2. G стоит раньше F.
3. D стоит на нечётной позиции.
4. Между B и C ровно одно место.
5. Между G и F ровно одно место.
6. C соседствует с A.
7. B стоит между E и D.
8. E стоит на нечётной позиции.

**Вопрос:** в каком порядке стоят модули слева направо?

**Вопрос:** какие переключатели включены?

## 005 · Порядок шести операций

Начальное состояние четырёх разрядов: `2047`.

Каждая операция A–F применяется **ровно один раз**, но порядок неизвестен.

- **A** — поменять местами 1-й и 4-й разряды.
- **B** — циклически сдвинуть все разряды влево на одну позицию.
- **C** — прибавить по модулю 10: `+1` к 1-му разряду и `+3` к 3-му.
- **D** — умножить каждый разряд на 3 по модулю 10.
- **E** — развернуть первые три разряда, четвёртый не менять.
- **F** — поменять местами 2-й и 3-й разряды.

После всех шести операций получилось `0571`.

**Вопрос:** в каком порядке были применены операции?

## 006 · Бинарная матрица 6×6

Заполните поле нулями и единицами.

Правила:

- в каждой строке и каждом столбце ровно три `0` и три `1`;
- три одинаковых символа подряд по горизонтали или вертикали запрещены;
- никакие две строки не совпадают полностью;
- никакие два столбца не совпадают полностью.

Дано (`·` — пустая клетка):

```text
0 0 · 0 · ·
· · 1 · · ·
· · · · · 1
0 · · 0 0 ·
· · · · · ·
· · · · · ·
```

**Вопрос:** восстановите всю матрицу.

## 007 · Башни 5×5

В каждой строке и каждом столбце должны стоять числа `1–5` без повторов. Число — высота башни. При взгляде с края более высокая башня закрывает все более низкие за ней. Число у края показывает, сколько башен видно.

Дополнительно известно: **клетка (строка 3, столбец 3) = 2**.

Краевые подсказки:

- столбец 3, сверху: `3`;
- столбец 4, снизу: `4`;
- столбец 3, снизу: `2`;
- столбец 5, сверху: `3`;
- строка 1, слева: `2`;
- строка 3, слева: `4`;
- строка 4, справа: `2`.

**Вопрос:** восстановите поле 5×5.

## 008 · Арифметическая сетка 4×4

В каждой строке и каждом столбце должны встречаться числа `1, 2, 3, 4` ровно по одному разу.

Клетки объединены в группы. Результат операции над числами внутри каждой группы указан рядом. Порядок чисел внутри группы для сложения/умножения не важен.

- `(2,1) (3,1) (4,1)` → сумма `8`;
- `(3,3) (3,4) (4,4)` → произведение `12`;
- `(2,2) (2,3) (3,2)` → сумма `6`;
- `(1,4) (2,4)` → произведение `4`;
- `(1,2) (1,3)` → сумма `7`;
- `(4,2) (4,3)` → сумма `5`;
- `(1,1)` → `2`.

Координаты записаны как `(строка, столбец)`.

**Вопрос:** восстановите всю сетку.

C—F 3    C—G 7
D—F 8    D—I 2
E—F 5    E—H 2    E—I 3
F—I 4
G—H 2
H—I 6

Нужно пройти из A в I, не посещая вершину дважды.

Дополнительные условия:

- маршрут содержит ровно **7 вершин**;
- суммарная стоимость ровно **23**;
- маршрут проходит ровно через одну из вершин `C` и `F`.

**Вопрос:** какой маршрут единственный удовлетворяет всем условиям?

## 010 · Цепь коннекторов

Есть восемь двусторонних плиток. Каждую можно переворачивать, и каждую надо использовать ровно один раз.

- A = `2—6`
- B = `3—6`
- C = `4—5`
- D = `4—6`
- E = `1—2`
- F = `2—5`
- G = `2—4`
- H = `3—4`

Соседние плитки должны соприкасаться одинаковыми числами. Цепь начинается с коннектора `1` и заканчивается коннектором `6`.

Дополнительно:

- C соседствует с G;
- A соседствует с G;
- A соседствует с D.

**Вопрос:** в каком порядке стоят плитки и какой стороной они повернуты?

## 011 · Пять карт

Есть 12 карт. У каждой три признака: цвет (`R/G/B`), форма (`C/T/S`) и число.

```text
A  R C 1      B  G T 2      C  B S 3
D  R T 4      E  G S 1      F  B C 2
G  R S 3      H  G C 4      I  B T 1
J  R C 2      K  G T 3      L  B S 4
```

Нужно выбрать ровно **5 карт**.

Условия:

1. Синих (`B`) карт ровно 1.
2. Если выбрана L, то выбрана F.
3. Карт формы `S` ровно 2.
4. Сумма чисел на выбранных картах равна 12.
5. Красных (`R`) карт ровно 1.
6. Если выбрана G, то выбрана J.
7. E и K либо обе выбраны, либо обе не выбраны.

**Вопрос:** какие пять карт надо выбрать?

## 012 · Шесть закрытых коробок

В коробках A–F лежат грузы массой `1, 2, 3, 4, 5, 6` кг — каждая масса используется ровно один раз.

Известны результаты измерений:

1. `A + B + D = 8`.
2. `|C − E| = 1`.
3. `A > F`.
4. `|D − F| = 1`.
5. `A + B + E = 10`.

**Вопрос:** какая масса находится в каждой коробке?
