# Premium Game Interface 1.2

Acceptance criteria:

- the investigation page is visually distinct from web 1.1 at first glance;
- one-event cases use the full dossier width instead of one seventh of the page;
- timelines adapt to the real number of events;
- facts are presented as evidence cards;
- testimony and notebook form one investigator workspace;
- the version board and result screen use the same visual language;
- mobile layout stays single-column and readable;
- `app-core.js`, answer logic, localStorage keys and paid-content boundary are unchanged.
