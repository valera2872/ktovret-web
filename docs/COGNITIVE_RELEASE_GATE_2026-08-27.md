# Cognitive Release Gate — 2026-08-27

## Зачем

Технический Release Gate отвечает на вопрос «игра работает и решение доказуемо?». Cognitive Release Gate отвечает на другой вопрос: «новый человек понимает, что происходит, думает о деле, а не борется с интерфейсом, и получает сложность того уровня, который ему обещали?»

## Проверяем каждый этап

1. Ориентация: кто эти люди, где мы, что произошло.
2. Ясность действия: игрок понимает, что ему делать сейчас.
3. Рабочая память: решение не требует помнить случайную деталь через 15–30 минут без контекстного напоминания.
4. Когнитивная нагрузка: имена, коды, временные отметки и сущности вводятся только в необходимом количестве.
5. Дедуктивная честность: вывод следует из уже доступных материалов.
6. Жизнеспособность альтернатив: до нужного момента остаются минимум две разумные гипотезы.
7. Калибровка сложности: «лёгкое/среднее/сложное/экспертное» соответствует объёму реального рассуждения, а не количеству текста.
8. Детективное ощущение: игрок расследует событие, а не решает школьное упражнение в детективной обёртке.
9. Темп: новая улика меняет вывод или действие; материал без функции считается трением.
10. Интерфейс: кнопки, этапы, возврат и порядок материалов очевидны без обучения.

### Решение

- новый посетитель каталога начинает с «Четыре входа в архив», а не с календаря;
- 001/002 остаются в библиотеке как логические вариации, но не представляют бренд первым экраном;
- завышенные уровни сложности первых 15 исправляются в player-facing web layer;
- технический `logicType` убирается из игрового hero, но остаётся в редакторских/SEO данных.

### AI detective preview

Статус: **зелёный по статическому UX**.

Первое действие понятно: выбрать подозреваемого и задавать собственные вопросы; новые доказательства открываются по ходу разговора. Основной риск — качество runtime-ответов модели, а не ориентация интерфейса.

## Телеметрия Cognitive Gate

События внутренних действий пишутся как `diagnostic_choice`, поэтому не искажают основную продуктовую метрику «осмысленное действие».

Solo 407:
- evidence open;
- requested evidence;
- hint + stage;
- checkpoint passed/failed + stage;
- navigation between stages.

Co-op 23:17 / 407 / Last Aria:
- stage navigation;
- hint;
- handoff/cross-check;
- intermediate decision;
- next stage;
- final submit.

Это позволяет отличить «не начал игру» от «начал, но сломался на конкретном этапе».

## Правило релиза

Новая игра не считается готовой только потому, что проходит технический walkthrough. Перед релизом обязательны:

- adversarial/fair-play gate;
- mobile/desktop smoke;
- Cognitive Release Gate;
- минимум один слепой проход новым человеком для больших дел, когда это возможно;
- после production — проверка реальной воронки и возврат к делу, если один этап даёт аномальный drop-off/подсказки/ошибки.
