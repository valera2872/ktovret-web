# Mystery Logic — ближайший продуктовый план (27.08.2026)

## 1. Сейчас: измерить реальный первый выбор

Не менять одобренный визуальный стиль главной без данных.

Новая воронка должна разделять:

1. вход на страницу;
2. 15 / 45 секунд вовлечения;
3. первый осмысленный CTA;
4. выбор формата solo / co-op;
5. открытие конкретного дела;
6. принятие короткого дела;
7. попытку ответа;
8. завершение;
9. показ и отправку отзыва;
10. переход к оплате.

Главные сегменты входа:
- главная;
- SEO-хабы;
- «Кто врёт?»;
- каталог бесплатных дел;
- игры для одного;
- игры для двоих;
- конкретное короткое / solo / co-op дело.

После накопления данных сравнить не только bounce rate, а `page view → meaningful action → game open → game accept → complete`.

## 2. Главная: экспериментировать только после baseline

Гипотеза: широкий запрос «детективные игры онлайн» приводит человека без заранее выбранного формата, а большое количество красивых блоков увеличивает когнитивную нагрузку.

Не делать ещё один редизайн. Возможный следующий A/B-вариант первого экрана:
- «5–10 минут» → «Кто врёт?»;
- «50–70 минут» → большое расследование одному;
- «Играть вместе» → игры для двоих.

Отдельно проверить мягкую мотивацию:
`15 дел бесплатно. Завершите любое, оставьте отзыв и получите 50 ₽ на большое расследование.`

Не добавлять большой рекламный блок со скидкой до baseline: он сам изменит измеряемое поведение.

Если цифр + Вебвизора всё ещё недостаточно, добавить один ненавязчивый диагностический вопрос:
`Что вы хотели найти?` → короткое дело / большое расследование / игру вдвоём / просто смотрю.

## 3. Отзывы

- Все отзывы принимаются независимо от оценки.
- Скидка не зависит от оценки.
- Согласие на публикацию хранится отдельно.
- Модерация: pending → approved / rejected.
- Отзыв без publication consent остаётся внутренней продуктовой обратной связью даже после одобрения.
- Публичный social proof размещать отдельным этапом после накопления реальных отзывов.

## 4. SEO и семантика «логические игры»

Вернуться к ранее собранному Wordstat-ядру и отдельно пересобрать кластер:
- логические игры;
- логические игры онлайн;
- логические игры в дорогу;
- логические игры для взрослых;
- детективные логические задачи;
- смежные интенты.

Не создавать страницы только ради частотности. Сначала проверить интент и пересечение с существующими:
- `/golovolomki-onlayn/`;
- `/zagadki-na-logiku-dlya-vzroslyh/`;
- `/logicheskie-detektivnye-zadachi/`;
- `/detektivnye-igry-onlayn/`.

Запросы «для детей» продвигать только если продукт и контент действительно подходят детям; не маскировать взрослую детективную игру под детскую ради трафика.

## 5. Telegram как retention, а не просто реклама

Канал должен давать причину вернуться:
- дело недели;
- короткий вопрос/улика/опрос без спойлера;
- новое большое расследование;
- подборки по типу логики;
- результаты игроков и одобренные отзывы;
- релизы новых дел.

После завершения дела можно тестировать CTA подписки, а не ставить его перед игрой.

## 6. Ассортимент после первых данных

Приоритет выбирается по фактической воронке:
- если сильный solo спрос → второе большое solo-дело;
- если co-op запускают и заканчивают → следующее большое дело для двоих;
- если короткие дела хорошо стартуют, но мало возвращаются → подборки / дело дня / тематические серии;
- Том 2 — после данных об использовании и продажах Тома 1;
- реальные cold cases — только там, где источник позволяет настоящую дедукцию, а не чтение архива.

## 7. Мобильное приложение

Веб-версия ушла далеко вперёд. Отдельный следующий продуктовый цикл:
1. сравнить приложение с текущей web-архитектурой;
2. перенести понятную продуктовую лестницу и актуальные бесплатные дела;
3. привести визуал и UX к Mystery Logic;
4. выпустить бесплатную версию;
5. связать app → web только в рамках правил магазина.

## 8. Конкурентный мониторинг

Регулярно сравнивать True Crime Games, Profile Detective, Home Detective, Rassledovanie.online, Kod Goroda и Dramtezi по:
- первому экрану;
- времени до первого действия;
- бесплатному входу;
- ассортименту;
- ценам;
- social proof;
- Telegram/VK;
- новым SEO-страницам;
- новым игровым механикам.

Цель — не копирование, а выявление ожиданий посетителя, которые Mystery Logic пока не закрывает.
