# Partner V2 — бесплатный локальный human playtest

Эта процедура запускает «Нулевой контейнер» локально с тем же Supabase-стеком, который используется в CI. Production Supabase и production-сайт не изменяются.

## Что нужно

- Node.js 22+
- Docker Desktop
- репозиторий `ktovret-web`, ветка `feature/partner-v2-zero-container`

## Вариант 1. Два браузера на одном компьютере

Из корня репозитория:

```bash
node scripts/partner-v2-human-playtest.mjs --open
```

Игрок 1 использует обычный браузер. Игрок 2 открывает тот же адрес в режиме инкогнито или в другом браузере, чтобы получить отдельный browser key.

Не открывайте обе роли в двух обычных вкладках одного профиля: у них будет общий `localStorage`, и это не имитирует двух независимых игроков.

## Вариант 2. Компьютер + телефон или второй ноутбук

Оба устройства должны находиться в одной домашней/Wi-Fi сети.

```bash
node scripts/partner-v2-human-playtest.mjs --lan --open
```

Скрипт определяет локальный адрес компьютера и открывает игру на компьютере **через LAN-адрес** вида `http://192.168.x.x:4173/...`. Этот же адрес можно открыть на телефоне/втором ноутбуке. Благодаря общему origin кнопка «Скопировать приглашение» создаёт ссылку, которая работает на втором устройстве.

В консоли также печатается резервный `127.0.0.1` адрес только для компьютера-хоста.

Backend при этом **не выставляется наружу напрямую**: браузер обращается к same-origin proxy тестового веб-сервера, а proxy уже передаёт запрос локальному `coop-case-v2` на `127.0.0.1`.

Режим `--lan` слушает локальную сеть только пока работает скрипт. Статический сервер отдаёт только страницу «Нулевого контейнера» и `/assets/`; остальные файлы репозитория недоступны.

Если Windows Firewall спросит разрешение для Node.js, разрешайте только **частные сети**, не публичные.

### Если выбран неправильный LAN-адрес

Docker Desktop, WSL, VPN и виртуальные машины могут создавать дополнительные сетевые интерфейсы. Скрипт автоматически предпочитает обычные `192.168.x.x`/Wi-Fi/Ethernet адреса и понижает приоритет Docker/WSL/virtual adapters.

Если всё же напечатан адрес, который телефон не открывает, укажите IPv4 компьютера вручную.

PowerShell:

```powershell
$env:PARTNER_V2_LAN_IP="192.168.1.25"
node scripts/partner-v2-human-playtest.mjs --lan --open
```

Windows CMD:

```bat
set PARTNER_V2_LAN_IP=192.168.1.25
node scripts\partner-v2-human-playtest.mjs --lan --open
```

Разрешены только приватные IPv4-диапазоны `192.168.x.x`, `10.x.x.x` и `172.16–31.x.x`.

## Что делает скрипт

1. Проверяет Docker и обязательные файлы проекта.
2. Поднимает локальный Supabase CLI `2.117.0`; облачный Supabase-проект не используется.
3. Применяет миграции проекта к временной локальной базе.
4. Запускает `coop-case-v2` локально.
5. Отдаёт настоящую страницу дела и на лету подменяет только `data-partner-endpoint` на локальный same-origin proxy.
6. При `Ctrl+C` останавливает Supabase с `--no-backup`, то есть тестовые комнаты удаляются.

Без `--open` браузер автоматически не открывается:

```bash
node scripts/partner-v2-human-playtest.mjs
```

## Начало партии

Игрок 1 создаёт комнату и сообщает восьмизначный код или отправляет скопированную ссылку игроку 2.

Игрок 2 входит в эту же комнату. На разных физических устройствах browser key автоматически независим; на одном компьютере используйте инкогнито/другой браузер.

## Что проверить руками

- старт без объяснений разработчика;
- понятно ли, что роли МАРШРУТ и ГРУЗ видят разные материалы;
- возникает ли естественная необходимость говорить вслух;
- карта Вектор-12 читается на телефоне и прокручивается горизонтально;
- на G02/M05 заметны три физических признака, но ответ не выглядит подсвеченным;
- после одной ошибки фото-checkpoint не становится раздражающим;
- после второй/третьей попытки подсказки помогают наблюдать, а не сообщают ответ;
- M09 сам по себе не доказывает мотив;
- G13 сам по себе не доказывает Маркову;
- только обмен M09 ↔ G13 позволяет уверенно объяснить WHY;
- ложь Савельева не воспринимается автоматически как доказательство его участия в краже;
- ручной HOLD Волковой не делает её автоматически организатором;
- refresh одного из браузеров не сбрасывает комнату;
- расхождение финальных версий заставляет обсуждать, но не сообщает, кто прав;
- правильный финал без G13 должен сообщить, что не хватает доказательства рыночной цели;
- после общей доказанной версии открывается полная хронология.

## Остановка

В терминале, где запущен playtest:

```text
Ctrl+C
```

Скрипт остановит локальный веб-сервер, Edge Function и удалит временную Supabase-базу.

## Важно

Этот playtest не создаёт Supabase Preview Branch, не использует платный staging и не развёртывает ничего на production. Даже в `--lan` режиме Supabase остаётся на loopback; наружу в локальную сеть проксируется только API этого тестового дела и только на время процесса.
